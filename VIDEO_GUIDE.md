# Recording the 3-minute video

The graders want three things on screen, in this order: **profile pages first, then the rankings**, with **the agents actually dating** in between. Aim for 2:50; 3:00 is a hard maximum.

## Before you record

- Season finished: 25+ people, all **Ranked**, rankings filled in.
- Browser window about 1440×900, page zoom 110–125%, bookmarks bar hidden, notifications off (Focus mode).
- Pick in advance:
  - **Person A**, whose profile you'll show: rich Instagram, clear needs.
  - **A first date that went well** (Rankings → Mutual matches → top one).
  - **A pair for the live date** (two people with overlapping hobbies).
  - **One new person to add live**: a friend who agreed, not yet in the system. Your own LinkedIn + Instagram works too.
- Record each segment separately (macOS: ⌘⇧5 → record selected portion). Add the voiceover afterwards.
- Speed up waiting (reading, a live date) 4–8× in the editor and put a small "4×" label in the corner. Never cut so it looks instant; say that it's sped up.

## Shot list and voiceover

| Time | Screen | Say (roughly) |
|---|---|---|

| 0:10–0:30 | `/add`: paste LinkedIn, paste Instagram, tick consent, **Send in the agent** → profile page shows *Fetching profiles*, then *Agent is reading* | "Two links go in. The agent fetches both profiles, the roles, posts, captions and the photos themselves, and starts reading." |
| 0:30–0:50 | Same page, **The reading** tab: notes appearing (LinkedIn on the left, Instagram with photo thumbnails on the right), then *What the agent saw in each photo* | "It reads like a matchmaker. Every note quotes the exact item it came from: this role, this caption, this photo. It looks at every picture." (sped up) |
| 0:50–1:25 | Person A's **Profile** tab: scroll Needs → click an evidence chip (jumps to the Instagram post under **Sources**) → back → Hobbies vs Interests → Values → Personality / Big Five → *What the agent couldn't tell* → the agent's brief | "Out comes the profile: needs, hobbies, interests, values, personality. Every claim links to its evidence. Click it and you land on the post. It also says what it couldn't tell, and writes a private brief for the agent: what to look for, and what it must find out on a date." |
| 1:25–1:35 | `/people`: scroll the 25 people | "We did this for 25 real people. Each one is two links, and each one has an agent." |
| 1:35–1:45 | `/dates?kind=speed`: scroll quickly | "First, every agent speed-dates every other agent: 300 speed dates, each ending with a private verdict." |
| 1:45–2:20 | `/live`: pick the pair → **Send them on a date** → the invite and plan appear, the reply, the scene, then messages streaming with private notes | "Then the real dates. Here, one agent asks the other out with a plan built from both people. Each agent only knows its own person. The notes in dashed boxes are private: what each agent is thinking for its human. The other agent never sees them." (sped up) |
| 2:20–2:35 | The finished first date you picked: scroll to **Outcome** and the two debrief cards (needs checked ✓ ~ ✗, best moment, second-date call) | "After the date, each agent debriefs its person: every need checked against what happened, the best moment, and whether to go on a second date." |
| 2:35–2:52 | `/rankings`: Person A's list (both agents' scores, mutual ♥) → **Mutual matches** → **Everyone × everyone** heatmap | "And for every person, a ranking of who fits them best. It's weighted toward their own agent's verdict, but the other agent has to agree too." |
| 2:52–3:00 | `/how`, or the landing page with the URL visible | "That's Proxima. Paste your own links and send your agent out." |

## Requirement checklist

- [ ] 25+ real people visible (`/people`)
- [ ] Links pasted in (`/add`)
- [ ] The reading shown, then the profile page with needs, hobbies, interests and other qualities
- [ ] Agents actually dating: a real date playing out turn by turn (`/live` → `/d/…`)
- [ ] Rankings shown after the profiles
- [ ] Under 3:00
